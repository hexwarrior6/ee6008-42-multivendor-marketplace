# 推荐分支整合更新（2026-10-11）

目标分支：`feat/recommendation-engine`。本次整合保留原分支 S4 模型源码、训练流程及首页/商品页推荐组件，并合入本地 S1 后端和前台修复；不修改 `main` 或 `development`。

## 更新内容

1. 推荐 API：读取 S4 原始导出 JSON，按登录用户、当前商品、默认列表选择结果；增加格式/大小/有效期校验、商品渠道与发布状态过滤、当前商品信息回填、身份隔离和规则降级。响应禁止共享缓存。
2. 前台推荐：保留 `listRecommendedProducts` 与 `listRecommendedProductIds` 两个适配入口，兼容新推荐组件和原有相关商品模块；增加公共 ID 适配的限量、去重、异常降级测试。
3. 定制订单：完善报价确认、状态流转、并发保护、独立分类初始化和角色权限；补齐支付集合、模拟微信支付、支付核验及管理员全额退款保护。
4. 分析接口：增加定制订单/核验扣款聚合，完善销售统计与店铺隔离；核验扣款快照不代表完整净收入或结算报表。
5. 结账修复：配送金额与零运费处理、地区币种刷新、购物车缓存、价格边界、Stripe 状态与配置缺失提示。
6. 工程交付：增加隔离数据库 HTTP 测试、单元/前台专项回归、环境变量模板和中文配置/验收文档。

## 验证与范围

- 后端：40 组、348 项单元测试，14 项隔离 HTTP 测试及类型检查通过。HTTP 包含实际调用 S4 训练、导出 JSON、再经 Medusa HTTP 返回推荐的场景。
- 合并后前台：推荐回归 11 项；币种 12 项、边界 17 项、结账状态 19 项、定制支付 12 项、定制申请 10 项，以及本地化、工匠档案检查和类型检查。
- 后端合并结果与通过上述后端验证的提交内容一致；S4 源码保持不变，独立副本自检 71 项中 2 项可选 LightFM 跳过，其余通过，离线流水线 smoke 通过。
- 联调使用模拟数据与 mock 支付；不代表真实推荐效果、真实到账或退款验收。前台未启动时的商品事件通知链路未验收。

## 部署注意

真实 `.env`、密钥和模拟训练输出不上传。部署时由负责人设置 `RECOMMENDATIONS_FILE`，指向 S4 交付的正式 `recommendations.json`；有效期通过 `RECOMMENDATIONS_MAX_AGE_SECONDS` 配置。未配置时自动使用规则推荐，不应为消除配置提示而把模拟模型当成正式数据。
